# SSD Charitia — Nonprofit & NGO Fundraising Website

A modern website concept for a nonprofit organization, designed to communicate social-impact initiatives and encourage visitors to learn about charitable causes.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/Nonprofit-NGO-Fundraising/)

## Project Overview

SSD Charitia is a front-end portfolio project in the nonprofit and fundraising category. The design focuses on presenting an organization's mission, causes, and ways to support its work.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Sublime Text or another code editor.
3. Open `index.html` in a modern web browser.

## Important Note

This is a demonstration website. Any donation or contact interactions should be connected to a secure, verified service before accepting real contributions.
